# 《三国群雄十策》与《我的球星融合系统》角色羁绊设计对比

> 版本说明：本文记录第二版 60 名基础球员、40 组羁绊时期的重构依据，保留用于版本对比。当前方案请结合 [第四版等级与羁绊效果正式方案](../v4-tier-and-bond-effect-proposal.md) 阅读。

## 一、结论

当前篮球版的问题不是羁绊数量不足，也不是角色覆盖不足，而是**不少组合只有数值逻辑，没有足够强的篮球故事逻辑**。

篮球版 60 名基础球员对应 40 组羁绊，人均参与 1.77 组；三国版 116 名可辨认角色对应 76 组羁绊，人均参与 1.69 组。篮球版每名基础球员都有羁绊，覆盖率和密度都不差。篮球版还有 7 组“二人关系升级为三人关系”的递进路线，结构上优于截图中三国版的 5 组嵌套关系。

真正的差距有四项：

1. 三国羁绊来自具体事件、亲缘、师承、阵营、宿敌和历史转折；篮球版主要来自曾经同队或相似打法。
2. 篮球版二人和三人羁绊大多可信，但四人、五人羁绊几乎都变成跨年代的类型拼盘，投入越高，故事感反而越弱。
3. 三国核心人物的关系会从不同人生阶段向外展开；篮球版头部球星关系集中，但缺少“搭档—王朝—宿敌—传承”的多轴网络。
4. 篮球版 33/40 组羁绊只有属性加成，组合之间的操作差异不够强。

因此不建议简单把羁绊从 40 组增加到 70–80 组。应先重做关系质量，尤其是四人和五人组合。

## 二、量化对比

| 指标 | 三国版截图数据 | 篮球版当前数据 | 判断 |
| --- | ---: | ---: | --- |
| 角色/基础球员 | 116 | 60 | 篮球版卡池较小，适合更紧密的网络 |
| 羁绊总数 | 76 | 40 | 与卡池比例接近 |
| 双人羁绊 | 48 | 24 | 两者均以易启动的小组合为主 |
| 三人羁绊 | 17 | 9 | 比例基本一致 |
| 四人羁绊 | 6 | 4 | 篮球版略偏多 |
| 五人羁绊 | 5 | 3 | 比例基本一致 |
| 人均参与羁绊 | 1.69 | 1.77 | 篮球版并不稀疏 |
| 只参与 1 组 | 73/116，62.9% | 26/60，43.3% | 篮球版普通球员复用率更高 |
| 参与至少 3 组 | 17/116，14.7% | 8/60，13.3% | 核心角色比例接近 |
| 最大羁绊数 | 刘备、诸葛亮各 8 | 詹姆斯 5 | 三国主角的叙事中心性更强 |
| 3 人以上组合包含小组合 | 5/28，17.9% | 7/16，43.8% | 篮球版的二人→三人递进更好 |

篮球版等级分布为青铜 7、白银 13、黄金 24、名人堂 16、传奇异名卡 10。基础球员的推荐槽位中，防守 19 人，占 31.7%；其余槽位仅 7–10 人。防守球员过密也促使当前设计出现多组“防守型人物拼盘”。

## 三、三国版设计好的地方

### 1. 羁绊名称本身就是一段故事

“三顾茅庐”“白帝托孤”“官渡决胜”“夷陵争锋”“宛城旧恨”不需要额外说明，玩家看到成员和名字就能理解组合原因。名称既承担识别，也提供收集动机。

篮球版的“水花兄弟”“紫金 OK”“雷霆三少”“南海岸三巨头”达到了同样效果；“得分万花筒”“中锋圣殿”“MVP 之巅”则更像系统分类，无法说明这些人之间发生过什么。

### 2. 关系类型丰富

三国版同时使用：

- 搭档与同僚：卧龙凤雏、虎卫双雄、五子良将。
- 亲缘与婚姻：江东二乔、孔明伉俪、袁氏兄弟。
- 师承与传承：衣钵相传。
- 君臣与托孤：三顾茅庐、白帝托孤、魏宫托孤。
- 战役共同体：赤壁风云、官渡决胜、水淹七军。
- 对手与恩怨：渭滨对垒、街亭得失、宛城旧恨、夷陵争锋。
- 地域、世家和派系：西凉马氏、荀氏叔侄、江东三世。

篮球版主要集中在“曾经同队”和“相似打法”，缺少宿敌、传承、同届、交易转折、总决赛对手、国家队和生涯事件等关系。

### 3. 核心人物拥有多条独立叙事轴

刘备的 8 组羁绊覆盖军师、让徐州、桃园、旧部、荆州、托孤、辕门和夷陵；诸葛亮的 8 组覆盖同门、君臣、传承、夫妻、宿敌、托孤、丞相群体和赤壁。即便两人共享几组关系，他们各自仍有不同的人生网络。

篮球版詹姆斯有 5 组，主要是韦德、欧文、戴维斯和顶级球星集合；库里、杜兰特各 4 组。关系数量够，但大多仍是队友或强者集合，没有完整表现球员生涯的不同阶段。

### 4. 大组合有明确历史锚点

五虎上将、五子良将、魏武谋臣、赤壁风云和官渡决胜都是玩家愿意主动收集的终局主题。它们虽然需要较多席位，却能提供清晰的身份和完成感。

篮球版现有五人组“中锋圣殿”“球场指挥官”“MVP 之巅”均是跨时代分类。其中“球场指挥官”放入凯尔·科沃尔尤其不合理：科沃尔可以支持三分效果，却不符合羁绊名称与成员身份。

## 四、篮球版当前设计的优点

### 1. 规模适合实际单局容量

单局最多 6 名首发和初始 5 名备战球员，40 组关系比照搬 76–79 组更容易理解和追踪。继续扩大数量会稀释招募提示，增加玩家记忆负担。

### 2. 小组合递进清晰

当前已有 7 条可信的二人→三人路线：

- 水花兄弟、勇士轴心 → 勇士王朝。
- 雷霆双少 → 雷霆三少。
- 热火双王 → 南海岸三巨头。
- 马刺基石 → 圣城三驾马车。
- 真理与狼王 → 绿军三巨头。
- 公牛双翼 → 公牛铁三角。
- 紫金 OK → 紫金关键组。

这类路线非常适合 Roguelike 招募：二人即可得到即时回报，第三人提供明确追求。应保留并扩展到四人、五人阶段。

### 3. 多数二人组合合理

水花兄弟、紫金 OK、公牛双翼、热火双王、克城之约、湖人双核、雷霆双少、马刺基石、挡拆教科书等都具有明确篮球记忆点，效果也基本对应打法。

## 五、篮球版主要问题

### 1. 高阶组合真实性骤降

24 组双人羁绊中大部分是真实搭档，9 组三人羁绊中也有 7 组是真实核心阵容；但 4 组四人和 3 组五人基本都是跨队、跨年代的类型集合。

问题较明显的组合：

| 羁绊 | 问题 |
| --- | --- |
| 锋线封锁 | 伦纳德、保罗·乔治、阿奴诺比只是同类型球员，没有共同故事 |
| 太阳轨道 | 纳什、布克、保罗横跨不同太阳时期，不是真实三人核心 |
| 禁飞区 | 霍勒迪、怀特、鲍文、巴蒂尔来自不同体系，是防守标签拼盘 |
| 护框议会 | 四位中锋只有类型相同，缺少事件或传承关系 |
| 得分万花筒 | 四位得分手的组合边界含糊，可替换成员太多 |
| 冠军拼图 | 霍里、卡鲁索、钱德勒、阿泰斯特没有共同阵容或统一事件 |
| 中锋圣殿 | 仅以位置集合，构筑合理但叙事弱 |
| 球场指挥官 | 科沃尔与“指挥官”定位冲突，为了效果硬塞成员 |
| MVP 之巅 | 单纯集合最强球员，容易成为无条件最优答案，缺少独特故事 |

玩家为五人组合投入近一半阵容容量时，得到的却是最泛化的关系，这是当前“感觉一般”的核心原因。

### 2. 缺少对手关系

三国版会把敌对、失败、恩怨也做成羁绊。篮球版却几乎只有正向队友关系。篮球世界里最有辨识度的内容之一正是竞争：魔术师与伯德、詹姆斯与库里、科比与邓肯、奥尼尔与奥拉朱旺、乔丹与活塞体系等。

宿敌羁绊可以提供不同于队友羁绊的效果，例如关键分、落后追分、对高评分对手加成或失败后士气保护，使故事直接转化为玩法。

### 3. 羁绊效果同质化

40 组中有 33 组只有属性加成，仅 7 组涉及奖金或招募。多数决策最终都变成“哪几个数字更大”。即使人物关系合理，实战体验也很难拉开。

建议建立效果类型：

- 搭档：提高对应槽位贡献或让两名成员的专属天赋同时增强。
- 王朝：逐关成长，连胜越多越强。
- 宿敌：面对高评分或特定打法时触发。
- 传承：低等级卡与高等级卡共同上阵时提高成长或训练效率。
- 角色球员群：提供奖金、免费刷新、装备栏或备战席收益。
- 同届/国家队：提高招募概率、刷新保留或跨槽位适配。

### 4. 球员功能分布偏斜

60 名基础球员中有 19 人推荐防守槽，而三分与突破各 7 人。防守池过大，会让防守相关球员在招募中互相替代，也容易催生只靠类型拼接的羁绊。需要重新检查部分球员是否更适合篮下、中投或控球槽。

### 5. 部分命名与成员不一致

“绿军后场”包含塔图姆，名称不准确；“球场指挥官”包含科沃尔；“纯粹射手”虽符合类型，却不是一段明确关系。这类不一致会让玩家迅速意识到组合是为了凑数值设计的。

## 六、建议的重构方向

### 第一优先：保留优质二人/三人关系

保留真实且容易识别的队友组合，以及现有 7 条二人→三人路线。少量修改名称不准确的组合。

### 第二优先：重做全部四人和五人羁绊

四人、五人羁绊应只采用以下来源：

1. 真实冠军或王朝核心阵容。
2. 同一支国家队或明确赛季阵容。
3. 有公认称呼的历史群体。
4. 能从现有二人、三人组合自然升级的关系。

如果当前 60 人卡池无法组成可信的四、五人组，应调整球员名单，引入对应角色球员，而不是用跨年代巨星补人数。

### 第三优先：补充三类篮球关系

- **宿敌**：魔术师×伯德、詹姆斯×库里、科比×邓肯等。
- **传承**：乔丹×科比、传奇内线或球队代际核心，但名称和效果要明确表达传承而非共同效力。
- **事件**：总决赛对决、经典逆转、选秀同届、国家队、重要交易等。

这会让关系网从“队友名单”升级为“篮球历史网络”。

### 第四优先：把效果从加法改成机制

每种关系类型拥有一套可识别的触发逻辑，平坦属性加成只作为基础收益。五人终局羁绊不应只是四项属性各加若干点，而应改变本局策略，例如让一次失败不扣士气、让连胜奖金递增或允许战前看穿对手策略。

### 第五优先：建立设计验收规则

新增或修改羁绊时必须回答：

1. 这些人为什么会被放在一起？一句话能否讲清？
2. 名称是否来自真实称呼、具体事件或清晰主题？
3. 其中任何一名成员换成同类型球员后，组合是否依然成立？如果成立，说明关系过泛。
4. 效果是否反映这段关系，而不只是补最强属性？
5. 大羁绊是否有小羁绊作为中途回报？
6. 它是否给玩家一条新的构筑路线，而不是强化已有最优阵容？

## 七、推荐目标

保持约 40–48 组羁绊，不追求与三国版相同数量。建议结构调整为：

- 20–24 组真实双人搭档或宿敌。
- 10–12 组真实三人核心或事件组合。
- 5–7 组由小组合升级而来的四人阵容。
- 3–4 组有明确历史锚点的五人终局组合。
- 至少 8 组非队友关系，包括宿敌、传承、同届和国家队。
- 至少一半羁绊具有属性以外的机制效果。

重构后，篮球版可以保留当前更适合 Roguelike 的网络密度和递进结构，同时获得三国版最强的叙事辨识度。
